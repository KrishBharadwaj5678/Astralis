## <img src="https://github.com/KrishBharadwaj5678/Astralis/raw/main/readme/gifs/howItWorks.gif" width="35"/> Как это работает

### 1️⃣ Скачайте изображения

- **Скачайте изображения** из папки `markers` в репозитории на своё устройство.

### 2️⃣ Скачайте приложение

- [Скачать приложение](https://drive.google.com/file/d/17-OUs8Y3uuJZaItPMiBOmMp69okh2GfS/view?usp=sharing) по предоставленной ссылке.

### 3️⃣ Запустите приложение

- **Откройте приложение**, чтобы начать погружение в дополненную реальность.

### 4️⃣ Отсканируйте изображение

- Отсканируйте **любое сохранённое изображение**, чтобы включить AR-режим.

### 5️⃣ Исследуйте космос в AR

- Изучайте **планеты в 3D** и исследуйте космос в дополненной реальности.
