## <img src="https://github.com/KrishBharadwaj5678/Astralis/raw/main/readme/gifs/howItWorks.gif" width="35"/> Como Funciona

### 1️⃣ Descarregue as Imagens

- **Descarregue as imagens** da pasta `markers` do repositório para o seu dispositivo.

### 2️⃣ Descarregue a Aplicação

- [Descarregar a aplicação](https://drive.google.com/file/d/17-OUs8Y3uuJZaItPMiBOmMp69okh2GfS/view?usp=sharing) através do link disponibilizado.

### 3️⃣ Inicie a Aplicação

- **Abra a aplicação** para começar a experiência imersiva de realidade aumentada.

### 4️⃣ Digitalize a Imagem

- Digitalize **qualquer imagem guardada** para ativar a realidade aumentada.

### 5️⃣ Explore em RA

- **Visualize os planetas em 3D** e explore o universo através da realidade aumentada.
