## <img src="https://github.com/KrishBharadwaj5678/Astralis/raw/main/readme/gifs/howItWorks.gif" width="35"/> 使い方

### 1️⃣ 画像をダウンロード

- リポジトリ内の `markers` フォルダから画像をデバイスにダウンロードします。

### 2️⃣ アプリをダウンロード

- [アプリをダウンロード](https://drive.google.com/file/d/17-OUs8Y3uuJZaItPMiBOmMp69okh2GfS/view?usp=sharing) してインストールします。

### 3️⃣ アプリを起動

- アプリを開いて、没入感のあるAR体験を始めましょう。

### 4️⃣ 画像をスキャン

- ダウンロードした画像をアプリでスキャンして、AR体験を開始します。

### 5️⃣ ARで宇宙を探索

- 惑星の3Dモデルを表示し、拡張現実を通じて宇宙を探索しましょう。
